# IdeaPad-Slim-3-IR-easyeffects
Little repository with the impulse-response files for convoluter in easyeffects for this laptop model to use in EasyEffects convoluter.
Files are provided AS they were recorded by me for this laptop model for each one of the sound modes available in Windows.
Personally, I like the movie mode sound the most but you can try to your taste and make your own modifications to the effects chain if needed.
